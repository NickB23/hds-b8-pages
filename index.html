HDS B8 Gmail Fallback

This is a small, personal automation used by one individual's home-network monitoring system. It sends a single automated email notification if a monitoring node in the operator's home network stack becomes unreachable, using Google's Gmail API with the gmail.send scope only.

It does not read, list, or delete any email. It is not a public product or service and has no other users besides its operator.

See the privacy policy for details on data handling.
